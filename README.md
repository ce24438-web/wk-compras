Para que todas as pessoas com acesso ao sistema vejam os mesmos registros, o ideal é hospedar o projeto em um servidor compartilhado ou em uma rede local com um arquivo central de dados.

Passos recomendados:
1. Instale o Node.js ou Python no computador que vai hospedar o sistema.
2. Inicie o servidor com: node server.js
3. Acesse o sistema via http://localhost:3000
4. Todos os usuários que acessarem esse mesmo servidor verão os mesmos dados.
